# تطبيق سيليا (أندرويد) — دليل البناء والنشر على Google Play

التطبيق مبني بـ **Capacitor** (واجهة ويب بتتغلّف كتطبيق أندرويد حقيقي) ومعاه **بلوتوث أصلي** و**ميكروفون وصوت أصلي**. نفس التصميم بتاع الصورة: البداية، الرئيسية، الشات (وش لايف)، الكاميرا والتحكم، الاتصال، إعداد الواي فاي، إعدادات Gemini، حالة الروبوت، الإعدادات. واجهة عربي/إنجليزي.

> **اللي اتجرّب فعلاً:** الواجهة وكل الشاشات (في متصفح محاكي)، رسم وش الروبوت، تدفّق الشات مع Gemini (برد وهمي)، وكود الروبوت (بيتكومبايل). **اللي لازم تجرّبه انت على جهازك:** البلوتوث الأصلي، الميكروفون والصوت، سيرفر MQTT الحقيقي، الكاميرا، وبناء الـ APK/AAB (مقدرتش أبنيه هنا لأن مفيش Android SDK ولا إنترنت عندي).

## محتويات المشروع
```
celyah-app/
  src/            كود التطبيق (الشاشات، الاتصال، Gemini، رسم الوش)
  assets/         أيقونة التطبيق وشاشة البداية (المصدر لتوليد أيقونات أندرويد)
  store/          كل حاجة صفحة المتجر: وصف عربي/إنجليزي، سياسة الخصوصية، Data safety،
                  أيقونة 512، Feature graphic 1024x500، لقطات شاشة (ar/en) 1080x1920
  scripts/        copy-vendor.js (مكتبة MQTT) + patch-android.js (الصلاحيات)
  .github/workflows/  بناء APK للتجربة + AAB موقّع للنشر (على GitHub بدون Android Studio)
```

## 1) كود الروبوت (الأول)
استبدل فولدر الروبوت بالجديد (فيه أوامر جديدة بيحتاجها التطبيق: `SPEED:` `GESTURE:` `STATUS` `ROT:` `WIFI:AUTO:` `CAMRES:` `CAMQ:`). ثبّت مكتبة **PubSubClient**، واختار البورد في `CelYah_Config.h`، وارفع.

## 2) بناء التطبيق — اختار طريقة

### الطريقة أ: من غير ما تثبّت حاجة (GitHub Actions) ✅ الأسهل للتجربة
1. اعمل حساب GitHub ومستودع (Repository) جديد، وارفع محتويات فولدر `celyah-app` فيه.
2. روح تاب **Actions** ← **Build Android debug APK** ← **Run workflow**.
3. بعد دقايق نزّل الملف `celyah-debug-apk` ← فكّه ← ثبّت `app-debug.apk` على موبايلك (اسمح بالتثبيت من مصدر غير معروف).

### الطريقة ب: على كمبيوترك
المطلوب: **Node 22+** و**JDK 21** و**Android Studio (Otter 2025.2.1 أو أحدث)**.
```bash
npm install
npm run build
npx cap add android
node scripts/patch-android.js       # صلاحيات البلوتوث والميكروفون + شاشة عمودي
npx capacitor-assets generate --android   # أيقونات أندرويد من فولدر assets
npx cap sync android
npx cap open android                # يفتح Android Studio، وشغّل على موبايلك (USB debugging)
```
لو `npm install` اشتكى من تعارض نسخ: الملف `.npmrc` بيحلها، ولو إضافة معيّنة ما اتثبتتش جرّب `npm view <اسم-الإضافة> versions` واختار نسخة تدعم Capacitor 8.

بعد أي تعديل في الكود: `npm run android:sync`.

## 3) أول استخدام
1. افتح التطبيق ← **ابدأ**.
2. **الإعدادات ← الاتصال ← بلوتوث** واختار الروبوت.
3. **واي فاي والإنترنت**: دوّر على شبكتك واكتب الباسورد.
4. **التحكم عن بُعد**: حساب HiveMQ Cloud المجاني (Host + مستخدم + باسورد) ← **حفظ وربط** ← **إرسال للروبوت (بلوتوث)**.
5. **الذكاء والشات**: ضيف مفتاح Gemini (مجاني من aistudio.google.com).
بعد كده تقدر تتحكم من أي مكان. الكاميرا بتحتاج بورد ESP32-S3-CAM و`HAS_CAMERA 1` وتشتغل عبر الإنترنت.

## 4) النشر على Google Play
### قبل ما تبدأ
- **حساب مطوّر Google Play**: رسم تسجيل **25$ مرة واحدة** + توثيق هوية.
- **الحسابات الشخصية الجديدة**: Google بتطلب **اختبار مغلق (Closed testing) بـ 12 مختبر على الأقل لمدة 14 يوم متواصلة** قبل ما تقدر تطلب النشر العام. (راجع الشرط الحالي في Play Console لأنه بيتغيّر.)
- **مستوى الـ API**: التطبيقات الجديدة لازم تستهدف **API 36** (من 31 أغسطس 2026). Capacitor 8 بيستهدف 36 تلقائياً ✓.

### الخطوات
1. **الـ Package name** `com.celyah.robot` (في `capacitor.config.json`). غيّره لاسم يخصّك **قبل** أول رفع — مينفعش يتغيّر بعد النشر.
2. **مفتاح التوقيع (مرة واحدة، احفظه في أكتر من مكان!)**:
   ```bash
   keytool -genkey -v -keystore celyah-upload.jks -alias celyah -keyalg RSA -keysize 2048 -validity 10000
   ```
3. **بناء ملف AAB موقّع**:
   - من Android Studio: **Build ← Generate Signed App Bundle** واختار `celyah-upload.jks`.
   - أو من GitHub: ضيف الأسرار `KEYSTORE_BASE64` و`KEYSTORE_PASSWORD` و`KEY_ALIAS` و`KEY_PASSWORD` وشغّل workflow **Build signed AAB**.
4. في **Play Console ← Create app**، ارفع الـ AAB في **Internal / Closed testing** الأول.
5. **صفحة المتجر** (من فولدر `store/`): الاسم والوصف (`listing_ar.md` / `listing_en.md`)، الأيقونة `icon-512.png`، `feature-graphic-1024x500.png`، ولقطات الشاشة.
   ⚠️ لقطات الشاشة اللي في `store/screenshots` متولّدة ببيانات تجريبية وصورة كاميرا **توضيحية مرسومة**. الأفضل تستبدلها بلقطات حقيقية من موبايلك قبل النشر عشان ما تتعارضش مع سياسة «المحتوى المضلّل».
6. **سياسة الخصوصية**: انشر `store/privacy_policy.md` على رابط عام (مثلاً GitHub Pages) واكتب الرابط في Play Console. عدّل `[DATE]` و`[YOUR EMAIL]`.
7. **Data safety** و**Content rating** و**Target audience**: استخدم `store/data_safety.md` كمرجع (راجعه مع تعريفات Google الحالية).
8. بعد الاختبار المغلق (12 مختبر × 14 يوم) اطلب **Production access** وانشر.

## 5) ملاحظات
- **آيفون:** المشروع للأندرويد. Capacitor يقدر يعمل iOS، بس محتاج Mac وحساب Apple مطوّر (99$/سنة).
- **أمان:** معرّف الروبوت (Topic prefix) وباسورد السيرفر هما اللي بيحموا الروبوت. ما تشاركهمش.
- **الفيديو:** عبر MQTT بتأخير ثانية أو أكتر، فسوق ببطء. الاستهلاك ~100-130 ميجا/ساعة.
- **السرعة:** شريط السرعة بيقلل سرعة العجلات بس، ومبيعدّيش أقصى سرعة اتظبطت في كود الروبوت (`WHEEL_DELTA_US`).
- **اتجاه الدراع:** لو الدراع بيتحرك عكس المتوقع غيّر `ARM_DIR` في كود الروبوت.
